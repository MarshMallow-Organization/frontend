# 마이페이지 데이터 소스 현황

> 상태: active
> 최종 확인: 2026-08-22
> 근거: `http://localhost:3000/swagger-json`, `src/pages/my-page`, `src/features`

이 문서는 마이페이지에서 실제 백엔드 API를 호출하는 값과 샘플 데이터로 표시하는 값을 구분한다. 화면 모양만으로 실제 데이터라고 판단하지 않는다.

## API가 연결된 기능

| 화면 영역           | API                                            | 연결 범위                                                          | 실패 시 동작                                    |
| ------------------- | ---------------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------- |
| 매수·매도 일지 현황 | `GET /diaries`                                 | 선택한 연도의 모든 페이지, 일지 유형·날짜·종목·수량·평균 가격·메모 | 해당 연도의 `MOCK_DIARIES`로 대체하고 경고 표시 |
| 관심종목            | `GET /users/me/favorite-stocks`                | 종목 코드·이름·market·등록일 목록                                  | `MOCK_FAVORITE_STOCKS`로 대체하고 경고 표시     |
| 관심종목 해제       | `DELETE /users/me/favorite-stocks/{stockCode}` | API 목록을 표시 중일 때 실제 삭제 및 실패 롤백                     | 샘플 대체 중에는 현재 화면에서만 제거           |
| 가상계좌 이름       | `GET /assets/portfolios`                       | 포트폴리오 id·이름·정렬된 목록                                     | `MOCK_VIRTUAL_ACCOUNTS`로 대체하고 경고 표시    |

공통 `apiFetch`는 access token이 있으면 Bearer 헤더를 넣고, 쿠키를 포함하며, 성공 응답의 `{ data: T }`를 해제한다. 오류의 HTTP status, `code`, `message`, `traceId`도 보존한다.

## API 결과에 샘플 값을 보강하는 기능

현재 Swagger DTO만으로는 Figma에 필요한 모든 필드를 만들 수 없다.

| 화면 영역     | API 값                     | 샘플 보강 값         | 이유                                     |
| ------------- | -------------------------- | -------------------- | ---------------------------------------- |
| 관심종목 행   | 코드, 이름, market, 등록일 | 현재가, 산업, 강조색 | 현재가·산업·로고 API가 없음              |
| 가상계좌 카드 | 포트폴리오 id, 이름        | 잔액, 분류, 강조색   | 포트폴리오 DTO에 자산 금액과 분류가 없음 |

API 목록이 정상적으로 비어 있으면 빈 상태를 표시한다. 정상 빈 응답을 샘플 목록으로 바꾸지 않는다.

## 전부 샘플 또는 브라우저 로컬 상태인 기능

| 기능                | 현재 구현                                                               | API 연결을 하지 않은 이유                                      |
| ------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------- |
| 프로필 조회         | 로그인 콜백이 저장한 사용자 정보, 없거나 손상됐으면 `MOCK_SESSION_USER` | 프로필 조회 API 없음                                           |
| 프로필 수정         | 이름·닉네임·이메일만 localStorage의 세션 사용자에 저장                  | 프로필 수정 API 없음                                           |
| 프로필 이미지       | 선택 직후 브라우저 미리보기만 제공                                      | 이미지 업로드 API 없음                                         |
| 비밀번호 변경       | 일치 검증만 하고 저장하지 않음                                          | 비밀번호 변경 API 없음                                         |
| Google 연결         | 편집 화면의 로컬 Switch 상태                                            | 연결/해제 API 없음                                             |
| 증권 API Key/Secret | 마스킹된 입력 시연, 저장하지 않음                                       | credential 저장 API 없음                                       |
| 이용 현황           | `MOCK_USAGE_SUMMARY`                                                    | 통계 API 없음                                                  |
| 주문 내역           | `MOCK_RECENT_ORDERS`                                                    | `GET /orders` 응답이 `object[]`로만 선언되어 안전한 DTO가 없음 |
| 로그아웃            | 사용자와 access token 로컬 캐시 삭제                                    | 서버 로그아웃 API 없음                                         |

## 대체 데이터 정책

- 기본 동작은 API 우선이며 별도 환경변수 없이 실제 API를 호출한다.
- 일지·관심종목·포트폴리오 요청 중 일부만 실패해도 성공한 영역은 API 값을 유지한다.
- 실패한 영역만 `src/pages/my-page/mock-data.ts`의 샘플로 대체한다.
- 하나 이상의 대체가 발생하면 화면 상단에 어떤 영역이 샘플인지 경고한다.
- 샘플 관심종목 해제는 서버에 요청하지 않으며 새로고침하면 복원된다고 알린다.

## 현재 로컬 백엔드 확인 결과

2026-08-22에 `localhost:3000`에서 다음 요청을 직접 확인했으나 모두 DB 오류로 HTTP 500을 반환했다.

- `GET /diaries`
- `GET /users/me/favorite-stocks`
- `GET /assets/portfolios`

따라서 현재 로컬 화면에서는 세 영역 모두 샘플 대체 경고가 보일 수 있다. 이는 API 연결이 빠진 것이 아니라 연결된 요청이 실패한 상태다. DB가 정상화되면 코드 변경 없이 API 데이터를 우선 표시한다.
