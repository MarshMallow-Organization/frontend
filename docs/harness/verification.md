# Verification Harness

> 상태: active-manual  
> 최종 확인: 2026-08-19  
> 근거: `package.json`, `.github/workflows/lint.yml`

현재 `format`과 `lint` 스크립트는 파일을 수정한다. 검증만 할 때는 아래 비수정 명령을 직접 사용한다. 통합 `check` 스크립트는 아직 없으며 로드맵에서 추적한다.

## 기본 명령

```bash
# 개발 서버
yarn dev

# 변경 파일 포맷 확인
yarn prettier --check <changed-files>

# 변경 TypeScript 파일 lint
yarn eslint <changed-ts-files>

# 전체 타입 검사
yarn tsc -b

# 타입 검사 + 프로덕션 빌드
yarn build

# 공백 오류와 남은 충돌 마커 확인
git diff --check
```

`yarn format`과 `yarn lint`는 자동 수정이 필요한 경우에만 사용하고, 무관한 사용자 파일까지 포맷하지 않는다.

## 위험도별 최소 검증

| 변경 종류            | 최소 검증                                                  |
| -------------------- | ---------------------------------------------------------- |
| 문서·주석            | 변경 Markdown Prettier, 로컬 링크 확인, `git diff --check` |
| 단일 컴포넌트 스타일 | 변경 파일 ESLint, 타입 검사, 해당 화면                     |
| 공용 컴포넌트·토큰   | ESLint, 타입 검사, 빌드, 모든 사용 화면                    |
| 라우팅·AppShell      | 빌드, 직접 URL, 탭 이동, 뒤로/앞으로, 인접 페이지          |
| API 래퍼·응답 타입   | 타입 검사, 성공·4xx·5xx·비 JSON·네트워크 실패              |
| 상태·비즈니스 로직   | 단위 테스트 또는 명시적 입력/출력 시나리오, 빌드           |

검사가 아직 자동화되지 않았으면 수동 시나리오와 결과를 완료 보고에 구체적으로 남긴다.

## UI 확인 항목

- Figma 기준 해상도와 일반 노트북·작은 화면
- 로딩, 빈 결과, 오류, 긴 텍스트
- 스크롤과 고정 영역, 겹침과 잘림
- 마우스·키보드 포커스·버튼 동작
- 직접 URL, 새로고침, 뒤로/앞으로
- AppShell과 인접 페이지 회귀
- 브라우저 콘솔의 신규 오류

## Definition of Done

- [ ] 요청한 사용자 동작 또는 문서 목표가 충족되었다.
- [ ] 공용 책임과 기능 전용 책임이 분리되었다.
- [ ] 변경 위험도에 필요한 검증이 통과했다.
- [ ] 로딩, 빈 결과, 오류 등 관련 상태를 고려했다.
- [ ] 임시값, 목업, 미구현 경로가 명시되었다.
- [ ] 실제 코드와 관련 문서가 일치한다.
- [ ] 무관한 기존 변경을 덮어쓰지 않았다.

## 완료 보고

- 바뀐 동작과 핵심 파일
- 실행한 검증과 결과
- 실행하지 못한 검증과 이유
- 남은 임시값, 목업, 미구현·위험
- 커밋과 푸시 여부
