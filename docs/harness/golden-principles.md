# Harness Golden Principles

> 상태: active  
> 최종 확인: 2026-08-19

1. `AGENTS.md`는 짧은 문서 지도여야 한다.
2. 실제 코드와 실행 가능한 설정이 문서보다 우선한다.
3. 에이전트가 읽을 수 없는 정보는 하네스의 일부가 아니다.
4. 중요한 규칙은 가능하면 lint, 타입, 테스트, CI로 강제한다.
5. 변경은 작고 되돌리기 쉬우며 독립적으로 검증 가능해야 한다.
6. 공용 계층은 페이지 전용 계층을 의존하지 않는다.
7. UI 완료에는 실제 브라우저 상태의 확인이 포함된다.
8. 실패를 숨기지 않고 재현 가능한 피드백으로 바꾼다.
9. 반복되는 실수는 개인 주의가 아니라 구조와 자동화로 해결한다.
10. 문서, 코드, 테스트가 어긋나면 같은 변경에서 다시 정렬한다.

원칙이 서로 충돌하면 사용자 목표와 안전을 우선하고, 선택한 trade-off를 실행 계획이나 완료 보고에 남긴다.
